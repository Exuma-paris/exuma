## Notes

- Dropez les photos de référence dans ce dossier avec le suffixe `-ref.jpg`
- Résolution minimale : 1 920 px de large
- Format : JPG ou PNG
- Pour les photos issues de services de presse, conserver le crédit photographe dans un fichier `CREDITS.md` à créer ici
